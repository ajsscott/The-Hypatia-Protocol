## My Learning Goal

Build deeper knowledge of Python data cleaning functions — enough to code
them myself, from memory, without looking them up. Scoped to whatever
aspects of data cleaning I encounter in the raw OnYourMark data
specifically. Timeframe: six months.

## Why It Matters

I want to own the work I ship, not vibe-code with Claude. I can read what
Claude writes now, but reading isn't literacy — writing my own without
asking anyone else is. That's the difference between reading a language
and speaking it.

## My Mechanism

Author as much as I can myself. Think through each script line-by-line in
logic first, then reach for Claude only to fill specific syntax gaps, one
small piece at a time.

## My If-Then Plan

- If I feel rushed to have Claude write the code, then I will take a
  breath, walk away for a minute, come back, and code the first version
  myself — no matter how rough — and only ask Claude for help after I've
  tried at least once.

## My First Step

In the next few days: look through the raw OnYourMark data. Just look. No
coding, no cleaning — build intuition for what's there before touching it.
