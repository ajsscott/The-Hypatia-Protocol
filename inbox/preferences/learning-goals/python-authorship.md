## My Learning Goal

I want to grow as a programmer so that eventually I do all the coding myself, and only ask Claude for help when I have a specific question. I will do this by attempting to code each task myself before I ask Claude for help, and by always typing in the code that Claude authors for me in the terminal into the scripts, files, and project myself by hand.

## Why It Matters

So that I actually become the machine learning engineer I want to be, rather than someone directing Claude to do all the work. The gap between the level I'm working at and the Python I actually know is real, and closing it requires doing the work with my own brain — not delegating it and stagnating.

## My If-Then Plans

- If I hit a moment of panic or overwhelm, then I will walk away from the computer for a minute, and when I sit back down I will open a new text file and write the algorithm in plain language before touching Claude.

## My First Step

Attempt every coding task myself before asking Claude, starting with the DIBELS work today.

## Check-in cadence

Every Friday. Assess: what did I attempt first? Where did the try-first discipline hold? Where did it break, and what was the trigger?
