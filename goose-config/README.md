# goose-config/

Hypatia's Goose configuration. **Launched live 2026-07-02** on Goose 1.40.0 —
everything below reflects verified reality, not the pre-launch guesses this
file used to carry.

## How Hypatia actually launches

```bash
hypatia            # full model (grows, heavy curation) — alias for scripts/launch-hypatia.sh
hypatia lite       # E4B light-burst tier (chat, PM, vault Q&A)
hypatia ask "..."  # one-shot question on the lite tier; answers and exits
```

The launcher pre-flights everything: Ollama up, think-shim on :11435
(auto-started if absent), model present, prompt/recipe/goosehints regenerated
from the kernel, then `goose run --recipe <recipe> --interactive` from
`~/GitHub/other` (the repo/vault parent — Goose hands the session cwd to MCP
servers as the filesystem root).

In-Obsidian sessions use the ACP path instead: see `docs/obsidian-setup.md`.

## The three delivery vehicles (Goose 1.40 has no system_prompt_file)

| Vehicle | Sessions it serves | Generated by |
|---|---|---|
| `hypatia-recipe.yaml` / `hypatia-lite-recipe.yaml` | Terminal (`goose run --recipe`) — carries kernel as `instructions`, extension set, model | `regen-system-prompt.sh` |
| `~/.config/goose/.goosehints` | ACP sessions (`goose acp` — Obsidian) which can't take a recipe | `regen-system-prompt.sh` |
| `~/.config/goose/config.yaml` extensions | ACP sessions' tool surface (recipes carry their own) | `docs/obsidian-setup.md` §2 patch |

`regen-system-prompt.sh` is the single generator: kernel/01-04.md →
`system-prompt.md` → embedded into both recipes + goosehints, with a shared
substrate note (absolute paths, wikilink referencing, time-tool discipline).
The launcher runs it on every start. All generated outputs are gitignored.

## The think-shim (delete when goose#7617 ships)

Gemma-4's hybrid thinking costs 60-90s per reply and Goose cannot pass a
thinking toggle to Ollama. `scripts/ollama-think-shim.py` (port 11435 →
11434) injects the disable: `think:false` on native endpoints,
`reasoning_effort:"none"` on `/v1/chat/completions` (the endpoint Goose
actually calls — the native field is ignored there, ollama/ollama#15288).
Gemma-4-family models only; transparent for everything else.
`~/.config/goose/config.yaml` points `OLLAMA_HOST` at the shim.

Keep-alive: `launchctl setenv OLLAMA_KEEP_ALIVE 1h` (set 2026-07-02) so the
model stays resident between turns; without it, pauses longer than 5 minutes
cost a full reload + re-prefill (~2 min at 30K context).
